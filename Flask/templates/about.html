About the Project

Productivity,
measured with data.

Employee productivity has a direct impact on operational efficiency and business outcomes. This project uses machine learning to estimate productivity from measurable workforce and production factors.

01 / Why this project

Turning workforce data into insight.

Employees are one of the most valuable assets of an organization. Understanding the factors that influence productivity can help organizations make better operational decisions.

This application provides a simple interface where workforce and production metrics can be entered and processed by a trained machine learning model to estimate employee productivity.

02 / Model

From input data
to prediction.

The application uses an XGBoost regression model trained to estimate the employee productivity value.

01

Input

Workforce, production and productivity metrics are provided through the prediction form.

02

XGBoost

The trained XGBoost regression model processes the supplied features and generates a prediction.

03

Classification

The predicted value is mapped to one of three productivity levels using defined thresholds.

03 / Input Features

What the model
looks at.

Thirteen measurable variables are supplied to the trained model for each prediction.

01 Work Context

  • Quarter
  • Department
  • Day
  • Team

02 Productivity

  • Targeted Productivity
  • SMV
  • Over Time
  • Incentive

03 Workforce

  • Idle Time
  • Idle Men
  • No. of Style Change
  • No. of Workers
  • Month
